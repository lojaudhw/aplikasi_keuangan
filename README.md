# 💰 Aplikasi Pencatatan Keuangan

Aplikasi Flutter untuk mencatat pemasukan dan pengeluaran uang dengan desain minimalis.

## ✨ Fitur

✅ **Input Pemasukan & Pengeluaran** - Ketik judul dan jumlah uang  
✅ **Kategori Otomatis** - Berbeda untuk pemasukan dan pengeluaran  
✅ **Pilih Tanggal** - Catat tanggal transaksi  
✅ **Saldo Real-time** - Lihat total saldo, pemasukan, dan pengeluaran  
✅ **Hapus Transaksi** - Hapus transaksi yang sudah tercatat  
✅ **Desain Minimalis** - Warna biru, hijau (pemasukan), merah (pengeluaran)  
✅ **Format Rupiah** - Tampil dengan pemisah ribuan

## 🚀 Cara Menjalankan

### Syarat:
1. Install Flutter dari [flutter.dev](https://flutter.dev/docs/get-started/install)
2. Setup Android Studio atau iOS setup (untuk build ke APK/IPA)

### Langkah:

1. Clone repository:
```bash
git clone https://github.com/lojaudhw/aplikasi_keuangan.git
cd aplikasi_keuangan
```

2. Install dependencies:
```bash
flutter pub get
```

3. Jalankan aplikasi:
```bash
flutter run
```

4. Atau build menjadi APK:
```bash
flutter build apk
```

## 📱 Struktur Kode

- `lib/main.dart` - File utama aplikasi
- `pubspec.yaml` - Dependency Flutter

## 💻 Teknologi

- **Flutter** - Framework untuk mobile app
- **Dart** - Bahasa pemrograman
- **Intl** - Package untuk formatting tanggal dan angka
